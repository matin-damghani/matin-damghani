## ▶️ How I structure projects
Each project I share typically includes:
- A clear README with a TL;DR and how-to-run steps
- A requirements.txt or environment.yml for reproducibility
- A small demo or sample data in `demos/` or `notebooks/`
- No large datasets or model weights committed directly; I provide links instead

Typical quick start for a repo:
```bash
git clone https://github.com/matin-damghani/<repo>.git
cd <repo>
python -m venv .venv
source .venv/bin/activate  # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
# then run the demo or notebook listed in the repo README
```
